# 末法仙途

> 一款在末法时代修仙的 2D 网页单机游戏——自由移动探索 + 回合制战斗 + 角色模拟养成。

---

## 这是什么

封神大战之后一千年，天庭以周天星斗大阵锁住天地灵脉，把灵气尽数收束于归墟。
又过两千年，大阵失序，灵气如退潮般枯竭——**末法时代降临**。

仙人或飞升、或陨落、或隐入凡尘。妖鬼再也修不成仙，只能以僵尸、鬼魅、精怪之身活在人间。
符箓驱邪、赶尸夜行，成了凡间的日常。

你从一座边陲小镇醒来，身负一缕尚未散尽的灵根，走在一条没人走过的成道之路上。

**核心命题**：在一个灵气已经死去的世界里，"修仙"这件事还成立吗？

---

## 玩法特色

- **自由探索**：在城镇、野外、秘境中自由行走，不踩格子；偏离主路才找得到的残碑与暗格
- **回合制战斗**：按速度排序行动，五行相克；技能、法宝与符箓自由搭配。**符箓不消耗灵力**——没蓝时的最后一根救命稻草
- **修仙成长**：凡人 → 炼气 → 筑基 → 金丹 → 元婴 → 化神，每境分初期 / 中期 / 后期 / 圆满。末法时代突破极难，要修为、要机缘、还要渡劫
- **抉择有代价**：正魔、门派、道侣、阵营——选了什么，就关掉另一扇门。**7 个结局**
- **聊斋式单元剧**：十六篇独立成篇的鬼狐故事，每一篇都有一个"说不清对不对"的选择
- **休闲养成**：灵田、炼丹、炼器、绘符、洞府建设、图鉴收集
- **电池卡带式存档**：手动存档点、三个槽位、"写入中…"进度条——像小时候换卡带那样
- **多周目**：继承功法与图鉴，敌人变强，解锁隐藏剧情与真结局

## 怎么开始玩

游戏是**纯前端静态网页**，不需要后端服务，也不需要联网。

```bash
pnpm install
pnpm dev
```

然后在浏览器里打开终端给出的本地地址。

> 当前仓库尚未初始化工程，以上两条命令会在首个开发阶段（M0）落地后可用。

---

## 环境要求

- 桌面端与移动端的现代浏览器（Chrome / Edge / Firefox / Safari 近两年版本）
- 支持 PWA：可安装到桌面并离线游玩
- **存档保存在你自己的浏览器里**，不上传任何服务器；换浏览器或清空站点数据会丢失存档，请用游戏内的导出功能备份
