## 五、全局约定速查

### 5.1 ID 前缀

ID 前缀的**登记表、编号规则，以及全部区域码 / 势力码 / 分类码**的唯一定义处是 [11-数据表规范](11-数据表规范.md) §2。

唯一不可违反的约束：一切 ID 为 ASCII 小写 kebab-case，**禁止中文 ID**；**ID 一经发布不改名**，只能弃用并新建。

### 5.2 术语

术语表（**唯一真源**）见 [01-世界观与设定](01-世界观与设定.md) §9。写作与写文案时一律使用该表用词，禁止自造同义词。

### 5.3 三条硬约束

1. **末法三大铁律不可被玩法绕过**（[01](01-世界观与设定.md) §3）：无真正的飞升、妖修不能成仙、符箓永远不耗灵力。
2. **数据驱动**：所有内容写进 JSON，代码只读表；未在 [11](11-数据表规范.md) §3.2/§3.3 白名单登记的 `effects`/`conditions` 一律视为配置错误。
3. **`runtime/` 只放临时产物**（[13](13-技术架构与工程约定.md) §7）：一切临时文件、测试工具、脚本产物只写 `runtime/`，永不提交。

## 七、唯一实现处登记表（代码侧）

> **规则**：同一职责**只有一个实现模块**。这是防止"生成重复代码"的硬约定（属于 §八 的**严格**档）。
> 新增模块前，先在此登记职责；出现第二个入口即为错误。

| 唯一实现处 | 职责 | 禁止 |
|---|---|---|
| `src/core/bus.js` | 跨层通信（`EVT` 常量 + mitt 实例） | `phaser/` 与 `vue/` 互相 `import`；散落事件名字符串 |
| `src/core/constants.js` | 魔法数字、`COEF_*` 系数、`PALETTE` | 模块内硬编码数字与颜色 |
| `src/core/registry.js` | 读取全部 JSON 配置表并建 `Map<id, entry>` 索引 | 其他模块自行 `import` JSON |
| `src/core/validate.js` | 配置表校验逻辑 | 在 `runtime/tools/` 里再写一套规则 |
| `src/core/effectRunner.js` | 执行 `effects` 白名单（改修为 / 灵石 / 物品 / 心境 / 声望 / 好感） | store 或 scene 直接改数值 |
| `src/core/conditionChecker.js` | 求值 `conditions` 白名单 | 各处自行写条件判断 |
| `src/core/saveManager.js` | 唯一接触 IndexedDB（读写、迁移、备份、恢复） | 其他模块直接开库 |
| `src/phaser/battle/DamageCalc.js` | 伤害 / 减伤 / 暴击 / 命中 / 保底计算 | 战斗 UI 或敌人各自再算一遍 |
| `src/phaser/battle/TurnManager.js` | 回合排序与行动调度 | scene 里自行排序 |
| `src/phaser/battle/EnemyAI.js` | 敌人决策 | 在敌人条目里写行为代码 |
| `src/phaser/systems/MapLoader.js` | 解析 Tiled JSON 与图层 | 各处自行解析地图 |
| `src/phaser/systems/TimeSystem.js` | 时间推进、昼夜、季节、天气 | 别处直接改 `time` 字段 |
| `src/vue/stores/*` | 只持有可序列化状态 | 保存 Phaser 对象（Sprite / Tween / 物理体）；写业务规则 |
| `src/data/*.json` | 全部游戏内容 | 代码里硬编码文案与数值 |

| 内容类型 | 规则 |

**动笔前的三问**：① 这个概念已经有定义处了吗？→ 有就只引用。② 没有 → 先登记到 §六。③ 涉及新模块 → 先登记到 §七。

## 九、文档维护规则

1. **新设定先登记**：新增区域、势力、NPC、境界信息 → 先写 [01-世界观与设定](01-世界观与设定.md)；新增 ID 前缀或字段 → 先写 [11-数据表规范](11-数据表规范.md)。
2. **唯一定义处原则**：见 §六。任何概念只允许有一个定义处，其他文档引用不复制；代码侧另见 §七。
3. **ID 一经发布不改名**，只能弃用并新建。
4. **先改文档再改代码**：设计变更先落到 `doc/`，PR 描述引用对应章节。
5. **文档间用相对链接**，不加空格；结尾统一 `**文档结束** · 变更记录见 [00-文档索引](00-文档索引.md)`。
6. **剧透隔离**：面向玩家的文案不得直接暴露真相线内容（[01](01-世界观与设定.md) §2.1）。
