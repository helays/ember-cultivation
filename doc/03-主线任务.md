## 一、主线设计总纲

### 1.1 目标

| 项 | 目标 |
|---|---|
| 主线任务总数 | **90 条**（一周目可达；二周目隐藏主线见附录 D，不计入 90） |
| 一周目通关时长 | 25~35 小时（主线 + 必要支线） |
| 境界跨度 | 凡人 → 炼气 → 筑基 → 金丹 → 元婴 → 化神 → 终章抉择 |
| 抉择节点 | **11 个**（其中 4 个影响结局判定） |
| 强制战斗 | 38 场（含 9 场 Boss/劫难战） |
| 结构 | 6 章 · 每章 3~6 幕 · 每幕 3~8 条 |

### 1.2 节奏设计原则

1. **每章一个"惊奇点"**：一章僵尸、二章剑冢/秘境、三章聊斋单元剧、四章四劫、五章真相、六章终章抉择。
2. **教学点前置**：每个系统在主线中都有一次"必须用到"的任务（见附录 C）。
3. **两章一升境**：一章末炼气、二章末筑基、三章末金丹、四章末元婴、五章末化神、终章抉择。不出现"打完一章还在原地"。
4. **抉择必须有代价**：所有抉择都写入 `flag-*` 并在后续任务中被引用，禁止只影响一句台词。
5. **伏笔链不可断**：真相的 5 处线索（一章残碑 → 二章古籍 → 三章三痕 → 四章阵图 → 五章归墟）必须在主线中强制经过，不可被支线跳过。

### 1.3 章节结构图

```
① 觉醒 ──▶ ② 入道 ──┬─▶ 茅山线 ─┐
   (凡人→炼气)  (三选一)  ├─▶ 昆仑线 ─┼─▶ 筑基 ──▶ ③ 游历 ──▶ ④ 劫难 ──▶ ⑤ 真相 ──▶ ⑥ 飞升
                        └─▶ 散修线 ─┘   (金丹)    (元婴)     (化神)      (抉择)
```

## 三、任务条目模板

主线每条任务按以下骨架展开（对应 [11-数据表规范](11-数据表规范.md) §4 的 JSON 字段）：

```
#### `mq-{章}-{序}` 任务名 · 类型标签
- **发布者**：`npc-*` 或 自动触发 ｜ **前置**：前置任务 ID
- **触发**：地图 + 昼夜/季节 + 条件
- **步骤**：① … → ② … → ③ …
- **战斗**：敌人 ID×数量（等级、特殊规则）
- **分支**：选项 → 后果 → 写入的标记
- **奖励**：修为 · 灵石 · 物品 · 声望 · 好感 · 图鉴
- **写入**：`flag-*`
- **关联**：`npc-*` / `enemy-*` / `map-*` / `item-*`
- **时限**：无 / N 时辰
```

**硬性约束**：每条任务至少有一项可见奖励；凡写入标记必须登记在附录 A；凡引用 ID 必须存在于对应表。

## 四、第一章 · 觉醒（8 条）

## 十、结局设计

| 结局 ID | 名称 | 判定条件 | 核心意象 | 周目加成 |
|---|---|---|---|---|
| `end-restore` | 星斗重明 | `flag-array-repaired` 且未满足更高优先级 | 大阵重新点亮，灵气缓缓回流，仙门开始重建秩序——但这一次，规矩由人间来定 | 修为获取 +5% |
| `end-break` | 天地自择 | `flag-array-broken` | 大阵碎裂，灵气散入天地，妖鬼第一次有了自己的路，代价是人间数十年的乱 | 妖修功法解锁 |
| `end-ember` | 末法成道 | 心境 `≥ 80` 且 `flag-final-break` 且未结道侣 | 你以末法之身证道，不靠灵气，只靠一条没人走过的路 | 打坐效率 +10% |
| `end-retire` | 人间烟火 | 结有道侣 且 `flag-final-repair` 且 `flag-repair-shared` | 大阵修好了，你没有留下名字，只留下一个人 | 道侣共修加成 +50% |
| `end-heaven` | 新天庭 | `flag-array-seized` 且 `flag-seize-rebuild` | 你成了新的执阵者，坐上了那张椅子——椅子上的人，最后都会被椅子改变 | 初始灵石 +2000 |
| `end-fail` | 轮回重来 | 终章关键战失败且选择放弃 | 一切推倒重来，残碑上又多了一行字 | 无（但记录在案） |
| `end-true` | 布阵者的旨意 | `flag-final-inquire` + `flag-united-inquiry` + `flag-shangyang-doubt` + `flag-answer-choice` + 图鉴完成度 ≥ 60% + `newGamePlus ≥ 1` | 你找到了当年那道旨意的出处，并把它公之于众——灵气不属于天庭，也不属于归墟 | 全部图鉴加成翻倍 |

> **判定优先级**：`end-true` > `end-heaven` > `end-retire` > `end-ember` > `end-break` > `end-restore` > `end-fail`。
> **多结局收集**：结局图鉴每解锁一个，周目继承加成叠加。
