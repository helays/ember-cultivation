> 本文档定义《末法仙途》的**物品内容层**：稀有度与价格区间、丹药、法宝、材料、符箓、炼丹配方、炼器配方、背包与交易规则、物品效果实现约定。
> 所有 ID 前缀、`category` 分类码、`level` 稀有度、`effects` 白名单以 [11-数据表规范](11-数据表规范.md) 为唯一真源；六势力风格以 [01-世界观与设定](01-世界观与设定.md) §4 为准；符箓不消耗灵力对应 [01-世界观与设定](01-世界观与设定.md) §3 铁律三。

## 一、物品分类与稀有度

### 1.1 分类码

`items.json` 的 `category` 字段只允许取 [11-数据表规范](11-数据表规范.md) §2.3 登记的七个值：

| 分类码 | 含义 | 堆叠 | 可售 | 典型前缀 |
|---|---|---|---|---|
| `dan` | 丹药 | 99 | ✅ | `item-dan-*` |
| `fabao` | 法宝 | 1 | ✅（部分绑定不可售） | `item-fabao-*` |
| `mat` | 材料 | 99 | ✅ | `item-mat-*` |
| `book` | 功法书 | 1 | ✅ | `item-book-*` |
| `fu` | 符箓（`tal-*` 的可用物品形式） | 99 | ✅ | `item-fu-*` |
| `quest` | 任务物品 | 1 | ❌ | `item-quest-*` |
| `misc` | 杂项 | 99 | ✅ | `item-misc-*` |

> **灵石的表达**：灵石是**货币而非物品**，不占背包格，不写入 `items.json`。需要表达"一袋灵石"时用 `effects: [{ "type": "stone", "value": N }]`。

### 1.2 六档稀有度（引用 [11-数据表规范](11-数据表规范.md) §3.1）

| `level` | 名称 | 颜色 | 价格区间（灵石） | 主要获得途径 | 掉落档位（[07-敌人与战斗设计](07-敌人与战斗设计.md) §9.1） |
|---|---|---|---|---|---|
| `common` | 凡品 | 灰白 | `10 ~ 60` | 商店常备、野怪档位 A、日常委托 | A |
| `fine` | 良品 | 绿 | `80 ~ 400` | 商店常备、精英档位 B、炼丹（基础配方） | A / B |
| `rare` | 珍品 | 蓝 | `600 ~ 2,500` | 支线稀有奖励、精英档位 B、炼丹（进阶配方）、`+50` 声望商店 | B |
| `epic` | 灵品 | 紫 | `4,000 ~ 16,000` | 支线传说奖励、首领档位 C、炼器（高级图纸） | C |
| `legend` | 神品 | 金 | `30,000 ~ 90,000` | 全流程唯一 1~2 件：终章首领首杀、图鉴 100% 奖励、隐藏支线 | C（终章首领） |
| `myth` | 仙品 | 赤 | `不流通（无价）` | 仅结局/多周目：三周目继承奖励、真结局分支 | — |

**价格与稀有度的硬约束**（校验脚本按此检查 `items.json`）：

1. 同 `category` 内，`level` 越高的 `price` 必须严格高于低档的**下限**：`common.max < fine.min < rare.min < epic.min < legend.min`。
2. `myth` 级物品的 `price` 字段写 `null`，`sellable: false`，商店永不收购。
3. `quest` 类物品一律 `sellable: false`、`price: 0`，且必须标注 `questSource`（产出任务 ID）。
4. 价格换算基准：`1 rare ≈ 3 fine ≈ 12 common`；`1 epic ≈ 8 rare`；`1 legend ≈ 6 epic`。所有新增物品必须落在此比例带内，偏差 > 30% 需在文档中说明理由。

### 1.3 品质浮动（法宝专属）

法宝除稀有度外还有**品质**，由炼器产出或掉落时掷定，影响属性加成 ±10%：

| 品质 | 概率 | 属性系数 |
|---|---|---|
| 劣 | 10% | `×0.90` |
| 常 | 60% | `×1.00` |
| 良 | 22% | `×1.08` |
| 极 | 7% | `×1.15` |
| 绝 | 1% | `×1.25`（并附加 1 条随机次要属性） |

品质影响**不改变物品 ID**，只写实例字段 `quality`。存档中法宝为实例对象：`{"id": "item-fabao-kunwu-jian", "quality": "极", "durability": 3}`。

### 2.3 与 [11-数据表规范](11-数据表规范.md) §5.1 的一致性

`item-dan-zhuji` 是 §5.1 的示范条目，本文档**逐字段对齐**，不得改动：

```json
{ "id": "item-dan-zhuji", "name": "筑基丹", "category": "dan", "level": "rare",
  "desc": "服下可增三成筑基把握。", "stack": 99, "price": 800, "sellable": true,
  "usable": { "inBattle": false, "inField": true },
  "effects": [{ "type": "flag", "key": "flag-zhuji-boost", "value": true }] }
```

- `price: 800` 落在 `rare` 区间 `600 ~ 2,500` 内，符合 §1.2 约束。
- 通过 `flag-zhuji-boost` 而非直接改数值，是**突破计算与丹药解耦**的样板：突破公式读 flag，丹药只写 flag。所有"突破辅助类"丹药（`item-dan-jindan-jiyuan` 等）沿用同一模式。

### 3.4 法宝耐久

- 每件法宝实例有 `durability`，初始 `3`。
- 天劫失败、"截教魔器"类主动效果使用 1 次、Boss 战失败 → `durability -1`。
- `durability = 0` 时法宝**属性加成减半**、主动效果不可用；在铁匠（`npc-zhang-tie`）或炼器堂（`npc-su-xin`）修理，费用为 `price × 5% × 缺失耐久`。
- `legend` 级法宝耐久上限 `5`，且不因天劫失败而降。

### 5.2 铁律三：符箓不消耗灵力

> [01-世界观与设定](01-世界观与设定.md) §3 铁律三 · **符箓护民**：符箓是**不含灵力也能使用**的资源。

实现约束（违反即为 bug）：

1. 符箓的 `mpCost` **必须为 0**；`talismans.json` 中**不应存在 `mpCost` 字段**。
2. 灵力为 `0` 时，符箓指令仍可正常下达与结算。
3. 符箓的强度**不随玩家境界增长**（不读攻击/灵力），只由符箓自身 `power` 与绘制品质决定。这使凡人与大能使用同一张驱邪符的效果一致——这正是符箓护民的世界观根基。

5. 符箓在战斗内消耗**道具**，且有`冷却 1 回合`（同一回合不能连甩两张同种符）。

### 5.3 全表

### 6.1 成功率公式与修正

```
实际成功率 = baseRate + 修正项，钳制于 [5%, 99%]

  + 悟性 × 0.5%（上限 +15%）
  + 丹炉等级 × 3%（洞府丹炉 0~5 级）
  + 道侣小蛮共修（`npc-xiao-man` 好感 ≥ 75）：+10%
  + 心境 ≥ 80：+5%；心境 < 30：−10%
  − (realmReq − 玩家境界) × 20%（越阶炼丹重罚）
  − 材料品质为"下品"时：−5% / 件
```

### 7.1 品质判定

```
品质掷骰 = 随机(0~1) + 悟性 × 0.005 + 炼器堂等级 × 0.02 + 法宝图鉴完成度 × 0.10
按 §1.3 的概率带映射为 劣/常/良/极/绝
```

- 法宝图鉴完成度 50% 时（[02-核心玩法系统](02-核心玩法系统.md) §9.1）额外获得 `+1 档` 的保底提升。
- `qualityRange` 是**上限钳制**：即使掷骰结果更好，也不会超过区间上界（防止低阶配方出绝品）。
- 炼器失败：材料损失 50%，产出 `item-misc-feicai`（废材，可作 1 份 `item-mat-xuan-tie` 回收）。
- 炼器耗时：`境界要求 × 1 时辰`；洞府炼器台可 `-1 时辰`（最低 1）。
- **图纸**：上表 5 条以上配方的 `craft-*` 需要先获得图纸（`item-misc-tuzhi-*`），图纸来源为秘境宝箱与图鉴奖励；`qualityRange` 中的上界只有拥有图纸时可达。

### 8.3 折扣规则

**NPC 好感折扣**（[02-核心玩法系统](02-核心玩法系统.md) §7，阈值 `25/50/75/100`）：

| 好感度 | 买入折扣 | 卖出加成 | 附加 |
|---|---|---|---|
| `< 25` | 无 | 无 | — |
| `≥ 25` | `-5%` | `+5%` | 解锁 1 条商品 |
| `≥ 50` | `-10%` | `+10%` | 解锁稀有商品位 |
| `≥ 75` | `-15%` | `+15%` | 可议价 1 次/日（额外 `-5%`） |
| `≥ 100` | `-20%` | `+20%` | 专属商品；道侣线可达 |

**势力声望折扣**（[01-世界观与设定](01-世界观与设定.md) §4.1）：

| 声望 | 效果 |
|---|---|
| `≥ 25` | 可入门；本势力商店开放 |
| `≥ 50` | 本势力商店买入 `-10%`；解锁专属功法与配方 |
| `≥ 75` | 本势力商店买入 `-15%`；解锁专属支线 |
| `≥ 100` | 本势力商店买入 `-25%`；解锁势力专属结局加成 |
| `≤ -25` | 本势力商店**拒售**；被其弟子在野外主动袭击（遇敌率 +50%） |
| `≤ -75` | 进入本势力领地触发战斗；通缉状态 |

**叠加规则**：好感折扣与声望折扣**相加**（上限 `-40%`），道侣共修加成（小蛮：炼丹 +10%）单独作用于**配方成功率**，不作用于价格。

### 8.4 出售价格比例

| 物品类别 | 常规商贩 | 黑市 `shop-heishi-luo` | 说明 |
|---|---|---|---|
| 材料 `mat` | `30%` | `40%` | 基础比例最高，鼓励采集 |
| 丹药 `dan` | `25%` | `35%` | — |
| 符箓 `fu` | `25%` | `30%` | — |
| 法宝 `fabao` | `15%` | `30%` | 品质 ≥ 良 时 `+5%`；绝品 `+10%` |
| 功法书 `book` | `20%` | `35%` | — |
| 任务物品 `quest` | **不可售** | **不可售** | `sellable: false` |
| `myth` 仙品 | 不可售 | 不可售 | `sellable: false` |

- 出售价格按 `price × 比例`（含好感/声望卖出加成）向下取整。
- **批量出售**：从背包多选出售，求和后一次性结算。
- **回购**：误卖物品可在**同一商店同一日**内以 `售价 × 1.5` 回购，每日上限 3 件。

### 8.5 任务物品规则

1. `category: "quest"` 的物品：`sellable: false`、`price: 0`、`stack: 1`（不堆叠）、**不可丢弃**。
2. 任务物品在背包中单独置顶分组，用**金色边框 + 锁定图标**与普通物品区分。
3. 任务完成后由任务的 `rewards` 或后续 `effects` 自动转化/清除（[02-核心玩法系统](02-核心玩法系统.md) §5）：
   - 转化示例：`item-quest-jiejiao-xin` → `item-misc-jiejiao-ling`（纪念品，可售）。
   - 清除示例：`item-quest-jindan-jiyuan` 在突破成功后由 `consume` 效果消耗。
4. 若任务被 `abandoned`，其专属任务物品在**下一个游戏日**开始时自动清除，并给出 `ui:toast` 提示。
5. **校验要求**：每个 `item-quest-*` 必须在 `quests.json` 中至少被一条任务的 `rewards.items` / `branches` / `conditions` 引用（[11-数据表规范](11-数据表规范.md) §7 校验清单第 2 条）。

### 8.6 快捷栏

- 4 格，仅可放 `dan` 与 `fu`（`usable.inBattle: true` 的丹药，以及全部符箓）。
- 战斗中点击快捷栏即 `consume` 1 个并生效；**符箓不检查灵力**（铁律三）。
- 快捷栏内容写入存档 `inventory.hotbar[4]`。

## 九、物品效果实现约定

### 9.1 硬性约定

1. **白名单强制**：所有 `effects[].type` 必须来自 [11-数据表规范](11-数据表规范.md) §3.2 白名单。`src/core/effectRunner.js` 对未知 `type` 直接抛错（开发模式 `console.error` 汇总，生产构建失败）。
2. **数值全在表里**：`effectRunner` 不得内联任何具体数值，所有参数从 JSON 读取（[13-技术架构与工程约定](13-技术架构与工程约定.md) §8 魔法数字条）。
3. **状态落档**：物品效果产生的状态变化必须落到存档字段（`worldFlags` / `inventory` / `relationships` / `factions`），不得只存在于运行时内存（[02-核心玩法系统](02-核心玩法系统.md) §12）。
4. **战斗内外分离**：`usable.inBattle` / `usable.inField` 决定效果在哪个上下文合法；同时为 `true` 时两个上下文都必须实现，否则校验器报错。
5. **`consume` 在主效果之前结算**：一次性物品的效果列表必须以 `consume` 开头，防止效果执行后物品仍在包内。
6. **符文类效果固定**：符箓的 `effects` 只允许 `hp` / `mp` / `mind` / `battle`（写入临时状态标志），**不允许出现 `mp` 扣除**。

### 9.3 校验清单（物品专属补充）

除 [11-数据表规范](11-数据表规范.md) §7 的通用清单外，物品表额外校验：

- [ ] 每个 `item-fu-*` 有且仅有一个 `tal-*` 与之对应，且 `talisman` 字段互指
- [ ] 所有 `tal-*` 的 `mpCost` 字段不存在或为 `0`（铁律三）
- [ ] `dan` 类物品 `stack` 必须为 `99`；`fabao` 与 `book` 必须为 `1`
- [ ] `quest` 类物品 `sellable: false`、`price: 0`，且被至少一条任务引用
- [ ] `myth` 类物品 `price: null`、`sellable: false`
- [ ] 同 `category` 内 `price` 满足 §1.2 的档位下限递增关系
- [ ] 所有 `alch-*` 的 `materials` 与 `result` 均可解析
- [ ] 所有 `craft-*` 的 `materials` 与 `result` 均可解析，且 `qualityRange` 上界不超过物品 `level` 允许的品质
- [ ] 法宝 `equip.slot` ∈ `weapon` / `armor` / `accessory` / `artifact`
- [ ] 所有 `effects[].type` 在 §3.2 白名单内（[11-数据表规范](11-数据表规范.md)）
