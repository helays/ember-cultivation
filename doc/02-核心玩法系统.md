# 02 · 核心玩法系统

## 一、系统总览与依赖关系

```
探索（自由移动）──触发──▶ 事件 ──▶ 对话 / 选择 / 战斗
     │                        │
     ├─遇敌──────────────────▶ 回合制战斗 ──▶ 奖励 ──▶ 背包 / 修为 / 声望
     │                        │
     └─采集 ──▶ 材料 ──▶ 炼丹 / 炼器 / 绘符 ──▶ 道具 ──▶ 战斗
                             │
                      修炼突破 ──▶ 境界提升 ──▶ 解锁地图 / 技能 / 任务
                             │
                      时间推进（时辰 / 昼夜 / 季节）
                             │
                      存档（洞府 / 客栈 / 宗门石碑）
```

**最小可玩循环**（必须先跑通）：`移动 → 遇敌 → 战斗 → 获得修为 → 存档`。

## 二、探索系统

### 2.1 移动

- Phaser Arcade Physics，**自由移动**（非格子对齐），八方向。
- 玩家物理体为**圆形**（半径 12px，贴图 32×48），比矩形更自然。
- 移动速度基准 `140 px/s`，奔跑 `200 px/s`（消耗轻体力或灵力，视设定阶段决定）。
- 摄像机跟随玩家，边界限制为地图尺寸；地图尺寸 < 视口时居中锁定。

### 2.2 碰撞

- 碰撞来源：Tiled 的**碰撞对象层**（`collision`），Phaser 直接读取生成静态体。
- 三类碰撞体：`wall`（不可穿越）、`water`（减速，特定境界可渡）、`trigger`（不阻挡，仅事件）。

### 2.3 交互

| 交互方式 | 触发条件 | 用途 |
|---|---|---|
| 交互键（`E` / 空格） | 玩家圆形与交互体距离 < 40px，且朝向一致优先 | NPC 对话、拾取、开关、存档点 |
| 踩踏触发 | 进入事件区域即触发 | 传送点、剧情演出、陷阱 |
| 自动触发 | 进入地图或满足条件即触发 | 章节开场、一次性剧情 |
| 距离遇敌 | 敌人圆形与玩家距离 < 遭遇半径（默认 60px） | 野外战斗 |

**交互优先级**：剧情自动触发 > 踩踏 > 交互键 > 遇敌。同时存在多个候选时，取**距离最近**且未被 `flag-*` 屏蔽者。

### 2.4 数据来源

| 内容 | 表 |
|---|---|
| 地图与图层、传送点、事件点 | `data/maps/*.json`（Tiled 导出） |
| 可交互物、采集点 | `data/maps/*.json` 的 `objects` 层 + `data/items.json` |
| 遇敌配置 | `data/maps/*.json` 的 `encounters` 字段 + `data/enemies.json` |

## 三、回合制战斗系统

### 3.1 触发与进入

- **野外遇敌**：距离检测触发（非踩格子）。进入战斗后玩家被推离遭遇半径，并进入短暂无敌期。
- **事件战斗**：由任务/事件指定 `enemy-*` 与胜负条件，可能有特殊规则（如"撑过 5 回合"）。
- **Boss 战**：多阶段，阶段切换播放演出，不重置回合计数。
- **心魔战**：对手是玩家自身的镜像（属性复制 + 心境污染机制）。

### 3.2 站位与行动顺序

- 玩家方最多 3 人（主角 + 2 同伴），敌方最多 5 个。
- 行动顺序按 **速度值降序**，同速时玩家优先；增益/减益可改变当前回合顺序。
- 每回合每人一个主动行动 + 可选的瞬发（法宝被动、部分符箓）。

### 3.3 指令

| 指令 | 说明 | 消耗 |
|---|---|---|
| 普攻 | 基础攻击，属性由武器决定 | 无 |
| 技能 | 主动技能，单体/群体/增益/减益/治疗 | 灵力 + 冷却 |
| 法宝 | 装备法宝的主动效果 | 视法宝 |
| 符箓 | 一次性法术，**不需要灵力** | 消耗符箓道具 |
| 防御 | 本回合受伤 -50%，恢复少量灵力 | 无 |
| 逃跑 | 成功率基于速度差；Boss 战与剧情战禁止 | 无 |
| 换人 | 替换场上同伴 | 该回合结束 |

### 3.4 伤害与结算

伤害、减伤、暴击、命中与保底公式的**唯一定义处**是 [16-数值设计](16-数值设计.md) §6。本节只约定结算**流程**：

1. 按技能倍率算基础伤害 → 2. 施加防御减伤 → 3. 乘元素克制 → 4. 乘随机浮动 → 5. 判定暴击 → 6. 取最低伤害保底 → 7. 结算到目标并触发飘字与受击反馈。

- 元素克制关系与倍率的唯一定义处是 [09-功法与技能体系](09-功法与技能体系.md)（五行克制）。
- 战斗回合数目标与战斗自洽校验见 [16-数值设计](16-数值设计.md) §7.4。

### 3.5 敌人 AI

| 类型 | 行为模式 |
|---|---|
| 攻击型 | 优先攻击血量最低者，血量 < 30% 时使用爆发技 |
| 防御型 | 前 2 回合加防，之后反击 |
| 辅助型 | 为友方加增益或治疗，被针对时逃跑 |
| 随机型 | 从行为表中按权重随机（新手友好，行为可预测性低） |
| Boss | 多阶段行为表，阶段切换有明确演出与弱点暴露 |
| 心魔 | 复制玩家技能，对玩家的心境值造成额外压力 |

### 3.6 奖励与失败

- **胜利**：修为、灵石、掉落（按掉落表概率）、首次击败解锁图鉴、任务进度推进。
- **失败**：不删除存档；在最近的存档点/客栈复活，损失部分灵石（`10%`），心境 `-5`。剧情战失败则重试同一战斗。
- **逃跑成功**：无奖励，敌人进入短冷却，玩家被推离。

## 四、修炼与突破系统

### 4.1 修为获取

修为的获取途径有 5 类：战斗胜利、任务奖励、打坐修炼、丹药与机缘、图鉴与成就。

**各途径的占比配比、按境界的场次换算与压力测试**的唯一定义处是 [16-数值设计](16-数值设计.md) §3，本节不复述具体数字。

### 4.2 打坐

- 在洞府、客栈、宗门静室可打坐，消耗 1 时辰，获得修为 = `基础值 × 功法系数 × 悟性系数 × 灵气浓度系数`。
- 末法时代**灵气浓度**是地图属性（野外 0.6~1.2，秘境 1.5~3.0，洞府可升级至 2.5）。
- 打坐时随机触发"顿悟"（+50% 本次收益）或"心魔侵扰"（强制战斗）。

### 4.3 突破

突破条件三要素：

1. **修为满**：达到当前小阶阈值。
2. **机缘物**：如筑基丹、金丹机缘、劫难令（见 [08-物品丹药与法宝](08-物品丹药与法宝.md)）。
3. **渡劫**：部分境界需通过天劫/心魔劫战斗。

```
突破成功率 = 基础成功率(境界表) + 根骨加成 + 心境加成 + 丹药加成 − 越阶惩罚
```

- 失败结果分三档：轻伤（掉修为 10%）、重伤（掉修为 30% + 心境 -10）、走火入魔（心境 -30，触发心魔战）。
- 成功结果：属性成长有**随机浮动区间**（随机机缘），并在区间内按根骨定位。

### 4.4 境界解锁

| 境界 | 解锁 |
|---|---|
| 炼气 | 技能系统、背包、战斗指令全开 |
| 筑基 | 门派/散修路线、洞府、灵田、炼丹、秘境 |
| 金丹 | 多城镇、道侣、势力声望商店、金丹技能 |
| 元婴 | 劫难关卡、同伴招募、高阶功法 |
| 化神 | 阵营抉择、多结局分支、化神技能 |

## 五、背包与物品系统

- 分类：丹药 / 法宝 / 材料 / 功法书 / 符箓 / 任务物品 / 杂项。
- 背包格数初始 `24`，最大 `120`，每次扩容 `+12`（费用递增，见 [16-数值设计](16-数值设计.md)）。
- 堆叠规则：丹药/材料/符箓可堆叠（上限 99），法宝与功法书不可堆叠。
- 任务物品不可丢弃、不可出售，任务完成后自动转化或清除。
- **快捷栏**：4 格，战斗中直接使用（丹药/符箓）。

## 六、技能与功法系统

- **功法**（`gongfa-*`）：修炼体系，提供被动加成、决定打坐效率、限制可学技能系别。
- **技能**（`skill-*`）：主动战斗技能，消耗灵力 + 冷却，可升级。
- **神通**：稀有高阶技能，需残页拼合，每部限 1~2 个。
- **符箓**：一次性，不消耗灵力，可在无灵力时救命（对应世界观铁律三）。
- 技能升级消耗"悟道点"（升级/任务/图鉴获得），详见 [09-功法与技能体系](09-功法与技能体系.md)。

## 七、关系系统

| 维度 | 范围 | 影响 |
|---|---|---|
| NPC 好感度 | `-100 ~ +100` | 对话选项、任务解锁、商店折扣、道侣条件 |
| 势力声望 | `-100 ~ +100` | 入门资格、专属商店、支线、结局 |
| 道侣 | 0/1 人 | 共修加成、专属剧情、结局分支 |
| 同伴 | 0~2 人上场（最多招募 6 人） | 战斗参战、被动辅助、专属任务 |

好感度阈值统一为 `25 / 50 / 75 / 100`，每档解锁一条内容（见 [06-NPC与关系系统](06-NPC与关系系统.md)）。

## 八、事件系统

### 8.1 事件类型

| 类型 | 前缀 | 说明 |
|---|---|---|
| 主线事件 | `mq-*` | 推进剧情，不可放弃 |
| 支线事件 | `sq-*` | 单元剧，可放弃 |
| 日常委托 | `dq-*` | 每日刷新，可重复接取 |
| 随机事件 | `rq-*` | 探索时按权重触发 |
| 季节事件 | `eq-*` | 按季节限定 |
| 劫难事件 | `mq-4-*` | 渡劫/剧情强制 |

### 8.2 事件结构

```json
{
  "id": "sq-qy-01",
  "title": "夜遇僵尸",
  "type": "side",
  "trigger": {
    "map": "map-qingyun",
    "timeOfDay": ["night"],
    "flags": { "flag-zombie-raid": true },
    "chance": 0.3,
    "once": true
  },
  "text": "……",
  "choices": [
    { "text": "战斗", "effects": [{ "type": "battle", "enemy": "enemy-zombie", "count": 1 }] },
    { "text": "逃跑", "effects": [{ "type": "move", "map": "map-qingyun", "spawn": "inn" }] },
    {
      "text": "用符箓",
      "conditions": [{ "hasItem": "item-fu-qixie" }],
      "effects": [{ "type": "consume", "item": "item-fu-qixie", "qty": 1 }, { "type": "flag", "key": "flag-zombie-warded" }]
    }
  ]
}
```

### 8.3 触发解析顺序

1. 检查 `once` 是否已触发（记录在存档 `worldFlags`）。
2. 检查地图、时间、季节、天气条件。
3. 检查 `flags` 前置与 `conditions` 条件。
4. 通过则按 `chance` 掷骰（`chance` 为 1 时不掷）。
5. 触发后写入 `flag-*`，如需可写入冷却计时。

## 十、时间系统

- 时间粒度：**年 / 月 / 日 / 时辰**（一日 12 时辰：子丑寅卯辰巳午未申酉戌亥）。
- 时间推进：移动累积步数、打坐、炼丹、战斗（每场 1 时辰）、任务节点。
- **昼夜**：昼（卯~酉）/ 夜（戌~寅）。夜影响敌人类型、NPC 出现、僵尸强度。
- **季节**：春（1-3 月）/ 夏（4-6 月）/ 秋（7-9 月）/ 冬（10-12 月）。影响灵田产出与季节事件。
- **月相**：每月十五为**月圆之夜**，妖鬼属性 +20%，专属事件触发。
- 时间不推进则无法刷新日常委托；长眠（客栈）可快进到指定时辰。

## 十一、存档系统（概览）

- 三处存档点类型：洞府石碑、客栈柜台、宗门石碑。
- 3 个可见槽位 + 1 个隐藏自动备份。
- 电池卡带式体验：写入进度条动画、"存档稳定性"装饰数值（纯氛围）、覆盖二次确认。
- 详细结构、迁移策略、周目继承见 [12-存档与时间系统](12-存档与时间系统.md) —— **该文档是存档结构的唯一定义处**，其他文档与代码中的存档字段一律以其为准。

---

## 十二、系统间的一致性约束

1. **所有系统必须从 JSON 表读数据**，代码中不得硬编码物品/敌人/任务内容。
2. **任何状态变化必须落到存档字段**（`worldFlags` / `relationships` / `factions` / `questProgress` / `codex`），不得只在运行时内存中存在。
3. **每条任务/事件的效果类型必须来自 [11-数据表规范](11-数据表规范.md) 注册的 `effects` 白名单**，不得临时发明。
4. **末法三大铁律不得被玩法绕过**：不存在真正的飞升、妖修不能成仙、符箓永远不耗灵力。
