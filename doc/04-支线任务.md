## 一、支线设计总纲

| 项 | 目标 |
|---|---|
| 支线总数 | **104 条** |
| 分组 | 10 组（按区域 / 主题划分） |
| 分级 | 普通 `common` 60% · 稀有 `rare` 30% · 传说 `epic`/`legend` 10% |
| 可放弃 | 全部可放弃（放弃不惩罚，但已消耗的资源不返还） |
| 依赖 | 支线可依赖主线，**主线不得依赖支线**（保证主线永远可通） |
| 设计定位 | 支线承担"世界质感 + 角色塑造 + 资源供给"，主线承担"推进与抉择" |

### 1.2 分级与奖励档位对应

| 分级 | 占比 | 修为 | 灵石 | 物品档位 | 前置要求 |
|---|---|---|---|---|---|
| `common` 普通 | 60% | 少 | 少 | `common`/`fine` 消耗品与材料 | 无 |
| `rare` 稀有 | 30% | 中 | 中 | `rare` 装备或法宝碎片、功法残篇 | 需完成 ≥ 1 条相关主线 |
| `epic` 传说 | 8% | 多 | 多 | `epic` 法宝 / 神通残页 / 同伴专属技能 | 需声望 ≥ 50 或好感 ≥ 50 |
| `legend` 神话 | 2% | 最多 | 最多 | `legend` 唯一物品 + 图鉴卡片 | 需结局相关前置（如 `flag-united-inquiry`） |

组内普通条目用表格给出（列见下），`sq-lv-` / `sq-cp-` / `sq-lz-` 三组因剧情密度高，另附详细条目块。

| 列 | 说明 |
|---|---|
| ID | `sq-{区域码}-{序}` |
| 名称 | 任务名 |
| 发布者 | `npc-*` |
| 前置 | 主线 `mq-*` 或支线 `sq-*` |
| 分级 | `common` / `rare` / `epic` / `legend` |
| 目标要点 | 步骤摘要（含地图） |
| 战斗 | 敌人 ID × 数量 |
| 奖励要点 | 修为 · 灵石 · 物品 · 声望 · 好感 · 图鉴 |
| 写入标记 | `flag-sq-*` |
